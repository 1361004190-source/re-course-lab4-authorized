## 课程作业要求

1. 定位卡密校验函数（`CHECK_FN`），给出文件偏移与反编译片段；
2. 说明校验逻辑：输入如何被变换、与什么常量比较；
3. 复原注册码生成算法，写出 `keygen.py`，至少通过 3 组自测用例；
4. （可选）Patch 校验分支，重打包后验证程序进入已注册状态；
5. 提交上述四项到 `solutions/<STUDENT_ID>/`。
